# tACS 头部—肩部回流：布局依据、楔前叶与 DLPFC、仿真及阻抗

整理日期：2026-10-24（Asia/Shanghai）

性质：讨论笔记；包含方法学解释、待核验的文献线索和后续验证清单。

## 1. 讨论范围与证据状态

本文整理以下问题：

1. 为什么某些 tACS 实验把一个电极放在三角肌上方？与全头部布局有什么差异？
2. 没有肩部 MRI 时，如何进行头部—肩部布局的电场仿真？
3. Pz—三角肌布局用于楔前叶（precuneus）研究的依据是什么？
4. 为什么一些 DLPFC 研究采用全头部布局，而不是肩部回流？
5. 肩部回流是否会使阻抗很高？既往文献是否提供具体数值？

初次讨论时文献站点访问受限；补充引用时，已能读取部分 PubMed 摘要及 Europe PMC 全文 XML。本文仍非系统综述。新增的[相关文献与证据说明](tacs-head-shoulder-references.zh-CN.md)逐篇标注核验层级，并确认一篇 Pz—右三角肌方案规定接触阻抗低于 5 kΩ；这不是受试者实测阻抗的统计结果。

| 内容 | 当前证据状态 |
| --- | --- |
| 电流回路、恒流输出、计算域和边界条件的解释 | 基础电路与体积导体建模说明 |
| 避免另一处头皮电极、改变电场方向等理由 | 合理的设计动机；具体收益需验证 |
| “很多楔前叶研究使用 Pz—三角肌” | 用户观察；未逐篇核查或统计使用频率 |
| “DLPFC 通常较少采用肩部回流” | 用户观察；未完成不同研究领域、tACS 与 tDCS 的分类统计 |
| Pz—三角肌比其他布局更聚焦、更有效或更安全 | 本次未获得足以支持这种普遍结论的直接比较证据 |
| 肩部回流的具体文献数值 | 已核实一篇方案的低于 5 kΩ 阈值；实测分布与布局间直接比较尚未核实 |

应避免把“被多篇研究沿用”“模型显示目标区有电场”“实验出现行为效应”和“布局优于其他方案”当作同一层级的证据。

## 2. 三角肌位置的电极起什么作用？

这里通常指贴在三角肌上方皮肤的头外电极，而不是插入肌肉的电极。其用途通常是与头部电极共同形成刺激回路，并非以刺激三角肌为首要目的。

“回流电极”是描述电路作用的便利称呼，不能将它理解为没有生理作用的地线。tACS 中电流方向随时间反转，两个电极及其位置都会影响电场、皮肤感觉和周围神经刺激。

采用肩部位置可能出于以下考虑：

- 避免直接在另一处头皮、例如额部，放置电极。
- 改变脑内电场的分布与方向。
- 避开某些头部接触位置，改变感觉体验；是否减少闪光感或提高盲法效果，需要具体检验。
- 沿用既有研究范式，保持结果可比性。
- 便于固定电极或安排较大的接触面积。

上述动机不自动意味着更好的靶向效果。电流会沿多个组织通路分布，而不是只沿两电极之间的一条直线流动。

### 2.1 与全头部布局的比较

| 方面 | 头部—肩部布局 | 全头部布局 |
| --- | --- | --- |
| 组织通路 | 需要考虑头、颈、肩及相关躯干组织 | 常规建模通常可采用头部计算域，仍需确认截断边界合理 |
| 另一处电极的影响 | 避免该电极直接覆盖另一处头皮，但不能消除非目标脑区电场 | 两个或多个头部电极共同决定脑内电场 |
| 空间选择性 | 不能仅凭回流距离远就认为更聚焦或更深入 | 普通双电极也可能产生广泛电场；多电极优化的效果需具体评估 |
| 感觉混杂 | 除头部感觉外，还要考虑肩部皮肤及周围神经刺激 | 要考虑头皮、颅周神经刺激和可能的闪光感 |
| 剂量比较 | 相同设定电流不代表相同的目标区电场 | 同样需要结合位置、面积、组织几何与电导率解释 |

### 2.2 周围神经效应不能忽略

tACS 的测量结果可能同时包含脑内电场的直接作用，以及皮肤、周围神经刺激经感觉传入产生的间接作用。相关运动系统研究提示，部分效应可由经皮周围神经刺激解释；不能据此推断所有 tACS 效应均来自外周。

比较头部—肩部与全头部布局时，脑内电场和感觉传入可能同时变化。常规短暂升降电流的 sham 未必充分匹配两种布局的感觉。根据研究目标，可考虑感觉匹配的主动对照、外周刺激对照，以及感觉和盲法评估。

## 3. 为什么楔前叶研究会选择 Pz—三角肌？

需要分别判断三个层次的依据。

### 3.1 为什么选择楔前叶作为靶点？

在情景记忆、阿尔茨海默病等研究中，楔前叶及邻近的后部默认网络与研究问题相关。部分研究因而选择调节这一带的活动。若使用 40 Hz，还涉及对 gamma 振荡的机制假设。

这些依据支持研究靶点或频率的选择，但本身不能证明肩部回流优于头部回流，也不能把所有楔前叶研究概括为同一种疾病机制或频率方案。

### 3.2 为什么使用 Pz？

Pz 是容易复现的后正中头皮定位点，可作为接近楔前叶区域的操作性定位。

但楔前叶主要位于大脑半球内侧面，Pz 不是其精确的解剖投影。个体脑沟回、头颅形状、电极位置与面积都会改变覆盖范围。应区分：

- “该研究使用 Pz 电极，意图靶向楔前叶”；
- “经模型或其他证据验证，该方案在楔前叶形成了预期的电场”；
- “该方案选择性刺激楔前叶，且优于替代布局”。

这三种表述需要不同强度的证据。

### 3.3 为什么回流放在三角肌？

可能的动机是避免在另一处头皮放电极，并改变后部脑区的电场分布与方向。另一部分原因可能是沿用已有实验方案。

这些是需要结合论文方法和引用链核查的解释，不应在未读原文时直接归为作者的明确理由。尤其不能仅凭电极位置认定：

- 电场一定更深、更强或更聚焦；
- 只有 Pz 下方脑区受到刺激；
- 肩部回流消除了其他脑区或周围神经的影响。

对于内侧面的楔前叶，应关注电场相对于局部皮层的方向，而不只是电场幅值或两电极的距离。

### 3.4 怎样判断论文是否真正支持这组布局？

直接文献入口：Benussi 等（2021）的摘要明确采用 Pz gamma tACS，Altomare 等（2023）的全文进一步明确 Pz—右三角肌方案。见[临床研究 R01](tacs-head-shoulder-references.zh-CN.md#r01)和[方案 R02](tacs-head-shoulder-references.zh-CN.md#r02)。前者不能仅凭摘要确认肩部位置，后者是方案而非已完成试验结果；两者均不构成回流布局优劣的直接比较。

| 论文提供的内容 | 能支持什么 | 仍不能单独证明什么 |
| --- | --- | --- |
| 引用既往使用该布局的研究 | 范式来源与可比性 | 布局最优 |
| 包含实际回流路径的电场模型 | 目标区电场及其分布估计 | 实际功能效应、个体剂量准确性 |
| 记忆改善、脑活动或连接变化 | 该方案与相应效应有关，具体因果强度取决于设计 | 效应只来自楔前叶，或肩部回流优于其他布局 |
| 直接比较不同布局，并处理剂量与感觉差异 | 布局相对优势的证据 | 对所有人群、参数和任务的普遍优势 |

如果论文只展示普通头部模型，需要进一步检查其肩部回流是否通过身体模型、扩展计算域或等效边界实现。不能只凭一张头部电场图认定实际方案已被完整模拟。

## 4. 为什么一些 DLPFC 研究使用全头部布局？

DLPFC 同样可以采用肩部回流，没有“楔前叶应该用头部—肩部，DLPFC 应该用头部—头部”的通用解剖学规则。

### 4.1 第二个额部电极可能就是方案的一部分

例如 F3—F4，或 DLPFC—对侧眶上区域等布局，两个电极共同决定额叶电场。有些研究关心双侧额叶或额叶网络，不能把第二个头部电极视作可以随意移动的附件。

将其移到肩部，会同时改变目标区和非目标区的电场，通常应视为新的刺激方案。

### 4.2 研究传统与可比性可能影响选择

部分常见 DLPFC 布局来自长期积累的额叶刺激研究，其中包含 tDCS 研究。沿用布局可以继承既有参数、耐受性经验和结果可比性，但这不等于证明肩部回流效果更差。

应按 tACS、tDCS、疾病、任务和研究目的分别查证，不能把一种技术中的使用习惯直接当作另一种技术的证据。

特别是，不能将部分 tDCS 文献中的“阳极兴奋、阴极抑制”简化解释直接套到 tACS。F3—F4 两电极交流刺激也不等于两个独立脑区的神经振荡相位得到独立控制。

### 4.3 建模与验证成本不同

全头部布局可利用较成熟的个体头部建模流程；肩部回流通常需要额外处理颈肩组织和边界条件，并重新评估感觉差异。对已有可用方案的研究，这些额外工作未必有明确收益。

“DLPFC 较浅，所以不需要肩部；楔前叶较深，所以需要肩部”不是充分解释。电极距离本身不能决定有效刺激深度。

目前本笔记未核实到足以支持“全头部回流对 DLPFC 普遍优于肩部回流”的直接比较证据。

## 5. 没有肩部 MRI，如何实现仿真？

不必一定采集受试者肩部 MRI，但回流路径必须存在于计算域中，或由经过验证的边界条件替代。不能把电极坐标移到头部网格之外，就认为已完成肩部电极建模。

### 5.1 三种方案

| 方案 | 实现方式 | 适用问题 | 主要局限 |
| --- | --- | --- | --- |
| 标准人体模型 | 使用含头、颈、肩及相关躯干组织的模板 | 初步比较布局、左右肩及位置变化 | 不能当作每位受试者的个体剂量 |
| 个体头部加模板身体 | 将 MRI 生成的个体头部与模板颈肩躯干连接 | 保留个体脑沟回，分析目标区电场 | 配准、组织衔接和网格处理较复杂 |
| 头部加等效颈部边界 | 用身体模型导出的边界信息替代颈肩躯干 | 经验证后的批量计算或简化分析 | 依赖近似的适用范围和验证质量 |

可调查的模型资源包括 IT’IS Virtual Population 中的 Duke、Ella 等人体模型。应另行确认许可、模型分辨率、可用组织和软件兼容性。模型资源存在，并不等于已有可直接运行的肩部 tACS 流程。

更直接的公开资源线索是 [Ernie Extended（Van Hoornweder 等，2024；R03）](tacs-head-shoulder-references.zh-CN.md#r03)：该模型含 13 类组织，延伸至第五胸椎水平，作者比较了扩展与非扩展模型的头外电极仿真。另见 [Im 等（2012；R04）](tacs-head-shoulder-references.zh-CN.md#r04)，其上半身模型明确比较左右三角肌等回流位置。两者都不等于本仓库已完成模型下载或仿真验证。

### 5.2 标准人体模型的建议流程

1. 准备连续的头、颈、肩及足够范围的躯干组织。通过扩大计算域、检查结果稳定性，判断身体截断是否足够远。
2. 建模实际电极位置、左右侧、面积、形状及接触层；肩部电极放在皮肤表面。
3. 设置大小相等、方向相反的电极总电流，明确峰值、峰峰值或 RMS 定义。
4. 求解脑内电场，分析目标区强度、方向和非目标区暴露，避免只比较全模型最大值。
5. 改变肩部位置、身体模板、颈部几何及组织电导率，评估结论是否稳定。必要时考虑颈部肌肉的方向性电导。
6. 检查电流守恒、网格质量，以及对网格密度和计算域范围的敏感性。

常规低频 tACS 的一种近似是使用准静态、纯电阻体积导体模型：

```text
∇ · (σ∇φ) = 0
E = −∇φ
```

其中 φ 为电势，σ 为组织电导率；考虑各向异性时，σ 可为张量。若研究需要处理频率依赖和电容效应，应使用适合该问题的复数导纳与界面模型，不能默认纯电阻模型能解释所有设备阻抗读数。

双电极电流边界可写成：

```text
I₁(t) = I_peak · sin(2πft)
I₂(t) = −I₁(t)
```

这里的正负号表示电流守恒，不能直接解释成两个脑区的神经振荡相差 180°。

### 5.3 个体头部与模板身体如何拼接？

基本流程为：个体头部分割 → 模板颈肩配准 → 组织与几何衔接 → 生成连续网格 → 求解与质量检查。

需要确认：

- 连接处没有缝隙、重叠或孤立组织。
- 皮肤、脂肪、肌肉及骨骼等组织在解剖上合理衔接，不能强行把不同结构一一相接。
- 没有意外绝缘面或异常高导电通路。
- 拼接区域、网格分辨率及模板选择不会主导目标脑区的结论。

SimNIBS 等工具可用于头部分割和电场计算，但常规头部流程不会自动生成肩部。使用自定义身体网格前，需要核对具体版本支持的网格格式、组织标签、电极接口及求解流程。

这里指常规个体头部流程的限制，不意味着不存在可用的扩展模板；Ernie Extended 已提供明确文献路线。ROAST 的方法学出处见[文献 R07](tacs-head-shoulder-references.zh-CN.md#r07)，不能仅因软件支持头部建模就假设它支持实际肩部位置。

### 5.4 能否在颈底直接设置回流？

可以作为探索性近似，但它模拟的是电流从颈部截面离开，而不是实际肩部电极。

直接将整个颈部截面设为零电势，会强制其成为等电势面。即使总电流正确，空间分布和目标区电场也可能与完整模型不同。

更可靠的简化方法，是先从包含身体的模型获得颈部截面的电势或电流信息，再构造适当的等效边界，并与完整模型比较。边界信息的适用性仍需在新的个体和布局下验证。

## 6. 肩部回流会不会使阻抗很高？

可能升高，但不能只根据距离判断。总阻抗同时受到电极接触、组织几何、电导率和频率影响。

一个用于理解的等效表达式是：

```text
Z_total(f) = Z_contact,1(f) + Z_tissue(f) + Z_contact,2(f)
```

这不是人体内部电流分布的完整描述。组织通路存在并联和分流，不能简单按单根导线的长度比较两种布局。

电极—皮肤接触阻抗往往是重要且变化较大的部分，受面积、导电介质、贴合、皮肤状态和毛发等影响。肩部更远，但通常较容易避开头发；两者对总阻抗的净影响需要实测。

### 6.1 恒流刺激器如何应对阻抗变化？

对于常用恒流设备，只要仍在输出电压能力范围内，阻抗升高首先意味着需要更高的输出电压，而非电流自动变小。

在简化的单频稳态模型中：

```text
V_peak ≈ I_peak × |Z_total(f)|
```

若超过设备的输出电压上限，可能出现输出电流不足、波形失真、报警或停止，具体取决于设备设计。应按设备要求检查实际输出，而不是只看设定电流。

不应通过增加设定电流来“补偿阻抗”。应先排查接触状态、导电介质、稳定性和设备输出能力。

### 6.2 三个不能混为一谈的问题

| 问题 | 应检查什么 |
| --- | --- |
| 能否输出设定电流？ | 输出电压余量、实际电流、波形和设备告警 |
| 电极接触是否良好？ | 阻抗稳定性、贴合、局部感觉及接触状态 |
| 目标脑区获得多少电场？ | 组织模型与电场计算；总阻抗不能直接回答 |

较低的总阻抗不自动意味着更高的脑内剂量；较高的总阻抗也不能直接归因于肩部电极。

### 6.3 仿真阻抗不一定等于设备测量阻抗

仅包含组织体积电导率的模型，可能未充分描述电极—电解质—皮肤界面。由模型电压和电流计算出的阻抗，不能未经校验就与设备显示值等同。

同时，设备的启动前阻抗检测可能使用直流、特定测试频率或特定测量算法，不一定等于实际 tACS 频率下的阻抗。应记录测量定义、时间点和设备型号。

## 7. 文献是否提供肩部回流的具体阻抗数值？

补充文献后，已找到可引用的具体方案阈值：**Altomare 等（2023）规定 Pz—右三角肌布局的接触阻抗低于 5 kΩ**。全文 **tACS parameters** 段写明“reduce contact impedance (< 5 kΩ for all sessions)”，并描述盐水海绵电极、导电凝胶及 Soterix Medical mini-CT。详见[文献 R02](tacs-head-shoulder-references.zh-CN.md#r02)。

需要保留三个限制：这是研究方案中的控制要求，不是实际队列阻抗均值；原文该段未充分定义测量频率和单接触点／回路读数，不能自行称为“肩部单电极阻抗”；该方案没有证明肩部回流比头部回流阻抗更高或更低。因此，实测分布及布局间直接比较仍待核查。

提取文献时需要区分：

| 报告类型 | 含义 | 不能据此推断 |
| --- | --- | --- |
| “阻抗保持在某阈值以下” | 实验接纳标准，或所有测量低于该上限 | 平均阻抗、分布及典型数值 |
| 均值、标准差、中位数、范围或随时间变化 | 实验实际记录的阻抗数据 | 设备未定义时的单个接触点阻抗 |
| 设备允许的最大阻抗 | 设备规格或操作限制 | 实验实际达到的阻抗 |

双电极刺激器显示的通常是回路阻抗，但具体定义应查设备说明。不能把回路数值直接称为“肩部电极阻抗”。

若要判断肩部回流是否比头部回流阻抗高，理想证据是在相同设备、测量频率、接触条件及电极面积下进行布局比较。跨论文直接比较不同设备的阈值，通常不足以回答该问题。

### 7.1 建议的文献数据提取字段

- 论文、年份、DOI，以及原文页码、章节或补充材料位置。
- tACS / tDCS 类型，频率、电流定义、时长。
- 两个电极的准确位置，包括肩部左右侧与定位方法。
- 电极材料、面积、形状、接触介质与皮肤准备。
- 设备型号、阻抗测量方法和测量频率。
- 数值性质：阈值、实测统计值、设备上限，或未报告。
- 测量时间点、样本量、波动和因阻抗异常退出的情况。
- 测量对象：回路、单通道或单接触点，以及原文定义。
- 是否提供全头部布局的直接对照。

## 8. 如何选择布局？

| 研究目标 | 选择与验证重点 |
| --- | --- |
| 复现已有研究 | 保留完整布局和参数，不能只保留头部电极位置 |
| 比较候选方案 | 先用包含实际回流路径的模型比较，再检查感觉与设备输出 |
| 保留个体脑沟回信息 | 考虑个体头部加模板身体，并量化拼接和模板不确定性 |
| 调整个体刺激剂量 | 对模型、身体模板误差和输出测量提出更高验证要求 |
| 研究两脑区相位关系 | 采用适合该问题的多通道设计和建模；普通双电极方案不能等同于独立相位控制 |
| 证明直接皮层机制 | 除 sham 外，考虑感觉匹配、外周刺激对照及可靠的脑活动测量 |

比较布局时，要区分“相同外加电流下的结果”与“匹配目标区电场后的结果”。两种比较回答的问题不同，都应明确剂量定义。
