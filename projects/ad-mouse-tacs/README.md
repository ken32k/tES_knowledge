# AD 小鼠 tACS 实验调研

建立日期：2026-10-28（Asia/Shanghai）。研究对象为阿尔茨海默病（AD）相关小鼠模型中的经颅交流电刺激实验。

按五个维度整理：

1. 模型小鼠种类：完整品系、基因型、背景、月龄、性别与病理阶段。
2. 评估指标：行为、病理、靶点参与、生理和技术质量指标分别定义。
3. 行为学测试：具体任务、指标、测试时间及运动／感觉等混杂。
4. 成像与细胞分子检测：技术、脑区、标记物、采样时间及因果证据。
5. 电极与设备：接触层级、刺激与回流位置、组件、设备、波形和实际剂量。

## 阅读与使用原则

- 正弦交流电、脉冲电流、直流叠加交流和感觉 gamma 刺激分别编码。
- 头皮、暴露颅骨、硬膜外／皮层电极等接触层级分别记录；按作者命名和实际方法双重分类。
- 小鼠、大鼠、人体研究分别统计；植入电极用于记录，不等于刺激本身为植入式。
- 背景模型与检测方法的介绍不是已经核实的“某篇 tACS 论文使用了这些方法”。
- 证据表只记录原文支持的信息；缺失、未访问和相互矛盾的信息不能混写为“未报告”。
